# ✂️ AudioCutter Pro - 高效音频批量裁剪工具

**AudioCutter Pro** 是一款基于 Python (wxPython) 开发的轻量级、可视化的音频裁剪与处理工具。它专为需要**批量处理**音频素材的用户设计，特别适合处理具有相同片头/片尾时长的录音文件、有声书或语音数据集。

### ✨ 核心亮点

  * **🌊 可视化波形编辑**：支持毫秒级精度的波形显示，支持鼠标滚轮缩放、左键拖拽平移，精准定位裁剪点。
  * **🤖 智能流水线操作**：
      * **自动流转**：当前文件处理完成后，自动选中并加载下一个文件，无需手动切换。
      * **进度标记**：处理成功的文件会自动标记为 ✅，防止重复操作。
  * **🧠 相对位置记忆**：**（特色功能）** 能够记忆上一次裁剪的“片头切除量”和“片尾切除量”。当打开新文件时，自动应用相同的裁剪方案，极大地提升了批量去除统一片头片尾的效率。
  * **🎛️ 丰富的导出选项**：支持音量均衡（归一化）、淡入淡出、采样率转换、声道转换及码率调整。
  * **🎧 实时预览**：支持光标跟随播放、暂停、点击定位，所听即所得。

### 🛠️ 安装与运行

#### 方式一：直接运行源码

如果你熟悉 Python，可以直接运行源代码。

**1. 环境要求**

  * Python 3.8+
  * FFmpeg (必须安装并配置环境变量，用于音频解码)

**2. 安装依赖库**

```bash
pip install wxPython pydub pyaudio matplotlib numpy
```

**3. 运行**

```bash
python AudioCutterPro.py
```

#### 方式二：使用打包好的可执行文件 (exe)

*(如果你已经使用 PyInstaller 打包，可以在这里提供下载链接)*

1.  下载 `AudioCutterPro.exe`。
2.  确保 `ffmpeg.exe` 和 `ffprobe.exe` 与程序在同一目录下（或已在系统 PATH 中）。
3.  双击运行即可。

### 📖 使用指南

#### 1\. 加载音频

点击左上角的 **“选择音频目录”** 按钮。

  * 程序会自动扫描该目录下的所有音频文件（支持 `.mp3`, `.wav`, `.ogg`, `.flac`, `.m4a`）。
  * 默认自动加载列表中的第一个文件。

#### 2\. 波形操作与预览

  * **缩放**：在波形区域滚动 **鼠标滚轮**，可放大/缩小波形（最高支持 10ms 精度）。
  * **平移**：按住 **鼠标左键** 左右拖动波形，查看不同时间段。
  * **播放/暂停**：
      * 点击底部的 **▶ 播放** 按钮，从绿色光标处开始播放。
      * 点击 **⏸ 暂停** 按钮停止。
      * 在波形上 **单击鼠标左键**，可快速定位光标位置。

#### 3\. 设定裁剪范围

  * **手动设定**：
    1.  移动光标到想要开始的位置，点击 **“设为起点”**（或是记住时间点）。
    2.  移动光标到想要结束的位置，点击 **“设为终点”**。
    3.  蓝色线为起点，红色线为终点，灰色阴影区域将被切除。
  * **自动记忆**：
      * 当你处理完第一个文件（例如：切掉了开头 5秒，结尾 3秒）。
      * 点击下一个文件时，程序会自动将起点设为 5秒，终点设为 (总时长 - 3秒)。你只需微调即可。

#### 4\. 导出设置

在右下角设置导出参数：

  * **淡入/淡出**：设置秒数，使音频过渡更自然。
  * **音量均衡**：勾选后可将音量统一标准化到指定分贝（如 -14dB）。
  * **格式转换**：支持导出为 mp3 或 wav，可自定义采样率（如 16000Hz用于语音模型训练）和码率。
  * **保存位置**：默认在源目录下的 `New` 文件夹中。

#### 5\. 执行处理

点击绿色大按钮 **“开始处理并保存”**。

  * 处理成功后，状态栏会提示保存路径。
  * 左侧文件列表当前文件前会出现 **✅** 标记。
  * **程序会自动加载下一个文件**，你只需要确认波形无误，再次点击处理即可。

### ❓ 常见问题 (FAQ)

**Q: 打开软件或导出时报错，提示找不到 FFmpeg？**
A: 本软件依赖 FFmpeg 进行音频转码。

  * **Windows 用户**：请下载 FFmpeg static build，将其中的 `ffmpeg.exe` 和 `ffprobe.exe` 放到本软件的同级目录下，或者将其 `bin` 目录添加到系统环境变量 `PATH` 中。

**Q: 波形图显示方框或乱码？**
A: 这是因为系统中缺少对应的字体。程序默认尝试调用微软雅黑 (Microsoft YaHei) 或文泉驿正黑。如果遇到此问题，请确保系统安装了常用的中文字体。

**Q: 为什么大文件加载稍微有点慢？**
A: 程序为了保证绘图流畅，在加载时会对音频数据进行降采样预处理。对于长达数小时的音频，这需要几秒钟的计算时间。
